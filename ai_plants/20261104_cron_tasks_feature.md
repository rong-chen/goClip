# 定时任务功能实现记录

## 1. 需求与设计概述
在 GoClip 中新增后台脚本定时任务功能：
- 用户可新建、编辑、删除定时任务，通过界面手选周期（间隔循环、每天、每周、每月固定时间），无需手写 Cron 表达式。
- 任务列表中直接展示人性化周期文本，对用户屏蔽底层 Cron 规则。
- 任务列表中不展示具体脚本内容代码块，界面保持简洁，仅在编辑弹窗中展示与修改。
- 任务卡片改为自上而下的分层结构：上部显示任务名称与周期标签，下部整排显示启用状态开关与操作按钮组（运行、日志、编辑、删除）。
- 脚本内容支持从本地文件一键导入并读取存储。
- 系统后台调度器按规则定时触发执行脚本。
- 捕获标准输出与报错信息，记录退出码与执行耗时，提供独立日志面板供用户查阅。
- 输入控件盒模型与高度统一为 38px，消除选择框与输入框的高度差异。
- 执行时间改为直接文本输入框，并使用 validateTimeInput 方法进行严格时间合法性校验。
- 顶部导航栏右侧按钮高度统一锁定为 32px，边框、圆角与内部图标大小完全对齐。

## 2. 后端实现
- 数据持久化：
  - 在 SQLite 中新增 cron_tasks 表与 cron_logs 表，建立 task_id 与 executed_at 索引。
  - 在 app/storage/model.go 中定义 CronTask 与 CronLog 数据结构。
  - 在 app/storage/cron.go 中提供任务与日志的 CRUD 方法。
- 调度引擎：
  - 新增 app/crontab 模块，使用 robfig/cron/v3 库管理调度器。
  - 支持任务执行超时控制与跨平台命令执行，实时捕获标准输出与错误报错并记录日志。
  - 支持手动立即执行与任务变动动态重载。
- Wails 桥接：
  - 在 app/app.go 中挂载 Scheduler 生命周期，并暴露任务与日志查询、保存、删除、启停、立即执行接口。
- 单元测试：
  - 在 app/crontab/scheduler_test.go 中添加脚本成功与错误退出的测试用例。

## 3. 前端实现
- 任务卡片布局重构：
  - 列表项隐藏脚本代码预览块，仅在打开编辑弹窗时显示。
  - 操作按钮组与启用状态开关移至卡片下方整排排列，形成上下分明、视觉整洁的卡片层次。
- 顶部按钮尺寸对齐：
  - 在 app/frontend/src/components/HeaderBar.vue 中，将 .status-btn 与 .icon-btn 高度统一锁定为 32px，配置 box-sizing: border-box 与 line-height: 1。
  - 内部图标尺寸统一为 14px，边框与背景色完全统一，消除两边方块按钮与中间文字按钮的高度错位。
- 执行时间自由输入与严格校验：
  - 彻底移除下拉框，恢复为标准单行文本输入框，用户可在键盘上自由打字如 17 或 17:30。
  - 新增 validateTimeInput 校验方法：
    - 校验格式：支持 HH:MM 与纯数字 HH 格式。
    - 校验范围：严格校验小时在 0 到 23 之间，分钟在 0 到 59 之间。
    - 校验通过后自动解析为有效时分参与 Cron 表达式组装，不合法则阻断提交。
- 周期手选与人性化展示：
  - 新建与编辑弹窗中无需手写复杂 Cron 表达式。
  - 改为周期类型下拉菜单：间隔循环、每天固定时间、每周固定时间、每月固定日期。
  - 根据手选类型动态切换配置项，保存时由前端自动组装为秒级标准调度规则。
  - 任务列表中展示如每隔 5 分钟、每天 10:00、每周一 08:30、每月 1 号 12:00 等直观文本。
- 脚本文件一键导入：
  - 脚本输入区右上角增加导入脚本文件按钮。
  - 通过 FileReader 本地读取选定脚本文件内容，自动填充入输入框，用户可直接查看、二次修改并保存。
- 控件高宽与盒模型对齐：
  - 将 .form-input 与 .form-select 高度统一设置为 38px，配合 box-sizing: border-box。
  - 重置 select 控件的原生外观属性，右侧定制平滑箭头指示器，使输入框、选择框及数字时间控件实现像素级对齐。
- 交互界面：
  - 在 app/frontend/src/views/CronTasksView.vue 提供完整的任务管理与执行日志查看功能。
  - 在 app/frontend/src/components/HeaderBar.vue 增加定时任务导航入口。
