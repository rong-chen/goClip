# v1.0.3 发布与打包记录

## 1. 版本发布内容
- 定时任务调度功能：
  - 新增后台 Cron 调度引擎与 SQLite 日志持久化。
  - 前端支持周期手选、文件一键导入、时间格式严格校验。
- 生产环境与开发环境数据隔离：
  - 开发模式使用 .goclip-dev，生产模式使用 .goclip。
- 主题全面升级：
  - 主题底色迁移至 #070709 极简深黑色系。
  - 顶部导航栏按钮尺寸锁定 32px 严格水平对齐。
- 打包与发布流水线优化：
  - GitHub Actions 流水线新增 macOS DMG 镜像自动构建与发布。
